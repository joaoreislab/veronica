# Contributing to Veronica

Start with a concrete problem: what you tried, what you observed, and what you expected. For bugs, include the environment, reproduction steps, and a sample without personal data.

Helper changes must preserve state consistency, evidence records, and resumption. Run the existing tests and add tests when a behavior change requires additional coverage.

Instruction changes must describe capabilities actually available in the environment. When proposing optimizations, provide the comparison method and observed results. Dependency count alone does not establish a performance gain.

A proposal should explain the problem, resulting behavior, verification, and limitations. Preserve the attribution of design references.
