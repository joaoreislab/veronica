# Veronica, an optimized Ruflo?

![Veronica poster](../assets/veronica-poster.jpg)

**🌸 Meet Veronica 1.2.0: a skill for AI projects that need continuity, careful execution and room to grow.**

Your project may take several sessions. Its requirements, discoveries and unfinished work need a place to survive them. Veronica gives your assistant a saved trail back to that work, along with tools to organize it and check the outcome.

## 🧭 Keep a long project moving

Save the goal, detailed inputs, tasks, dependencies, decisions and next actions in your workspace. Return with a handoff that points back to complete records and original files. Useful for apps, research, reports and projects improved over many rounds of feedback.

## 🤝 Coordinate pieces of work

When available and authorized, agents can take separate research, coding or review assignments. Veronica guides deliverables, cooperative reservations, writing areas, dependencies and handoffs. The lead assistant verifies how the pieces fit together; the host supplies the agents.

## 🧰 Put the right capability to work

Other skills, MCP servers, connectors, plugins, command-line tools, libraries or direct execution can help with a concrete gap. The assistant considers setup, context, resources and integration costs before choosing them.

## 💡 Reduce waste while preserving depth

Focused reads, literal search, exact artifact storage and guides loaded when needed reduce unnecessary repetition. Detailed originals remain available. Optional compaction is reversible and checked for byte equality. The workflow imposes no token quota or forced model downgrade.

Its approach adapts: simple work can proceed directly; larger projects benefit from focused context; independent tasks may justify agents; recovery procedures are available when needed. These are contextual choices, not fixed presets or automatic model routing.

## 🧳 A stronger foundation in 1.2.0

Verified recovery bundles, deeper diagnostics, interrupted-artifact reconciliation and task-index pagination join fixes for concurrent writes, restored files, status generation and long dependency chains. The main instructions stay compact, with deeper guides consulted for their specific jobs.

Underneath: **Python 3.10+, SQLite and the standard library**, with no resident service or additional runtime dependency. Instructions guide judgment; local code handles repeatable operations and saved state.

## 📊 Results with their units attached

The retained runtime passed **59 regression tests** and **261 controlled workflow executions**. One targeted-context comparison reduced evidence-hash calls **from 24 to 1**, with identical returned bytes. The earlier entrypoint reduction was **9.94% in bytes**. Enabling every module also added overhead, reinforcing selective use.

These measurements do **not** establish billed token or dollar savings. Original records support continuity within a finite model context; the assistant still needs to consult them and evaluate quality. See the [validation evidence](VALIDATION-1.2.0.md).

**Versioning note:** the feature package was initially published as 1.1.2. The new 1.2.0 release corrects its SemVer classification because it includes compatible new capabilities; the old tag is preserved.
