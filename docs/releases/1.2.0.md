# Veronica 1.2.0

🌸 **Long projects, clearer handoffs and stronger recovery.**

This release gives the feature package first published as 1.1.2 its correct semantic version. Compatible new capabilities belong in a minor release. The old tag is preserved; runtime behavior is retained, with updated version labels and a more accessible public presentation.

## 🧳 Capabilities introduced by this feature package

- Verified recovery bundles for process state, the artifact catalog and explicitly selected product files.
- Optional deep diagnostics for dependency, artifact and projection consistency.
- Saved capture receipts and explicit reconciliation after interrupted catalog writes.
- Pagination of unrelated task indexes while preserving selected task/dependency details and global notes.

## 🔒 Reliability improvements retained

- Reject malformed task, evidence and usage fields before committing unusable state.
- Serialize concurrent usage records and detect conflicting duplicate payloads.
- Stage and verify restored files before atomic promotion without overwriting existing destinations.
- Coordinate status generation with ledger writers and identify projection generations with revision and hashes.
- Traverse long dependency chains iteratively.
- Report invalid legacy usage records without silently treating them as complete.

## 🌸 Public presentation

- The original Veronica poster is the repository cover.
- A clearer English introduction explains long-duration workflows, agent coordination, tools, contextual approaches and efficiency.
- [Versioning policy](../VERSIONING.md) declares the public interface and future release rules.

## 📊 Validation

See [validation and retained benchmark evidence](../VALIDATION-1.2.0.md). Token/dollar savings and performance against Ruflo have not been established. Mechanical checks do not replace semantic review or prove indefinite stability.
