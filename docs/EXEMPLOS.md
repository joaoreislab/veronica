# Usage examples

These examples describe possible applications. They are not benchmark results or demonstrations executed in this document.

## Research across sessions

> Use $veronica to research five alternatives for this problem. Record primary sources, comparison criteria, uncertainties, and the next step. Deliver a report with verified conclusions.

The process can separate identifying alternatives, checking sources, and writing. The checkpoint preserves the status and continuation point. Relevant sources and artifacts become evidence of what was checked.

## Fixing software in stages

> Use $veronica to investigate this error, fix its cause, and verify the behavior. Preserve tested hypotheses and outstanding checks if the work is interrupted.

An observed reproduction can precede the fix. Completion records the tests that were run and the files involved. If an attached file changes, the evidence must be revalidated.

## Multiple documents from one research base

> Use $veronica to turn this research into a report and a presentation. Record dependencies, review the content, and verify each deliverable with the appropriate tools.

The assistant uses the document and presentation tools available on the host. Veronica records the dependencies between deliverables; the helper does not render slides or judge their appearance by itself.

## A demonstration for a short video

In a fictional workspace without personal data, prepare a task with a verifiable criterion, record one completion, and leave another stage pending. Generate a checkpoint. In a new session or process, read the resumption summary and show the actual pending item and next step.

Describe only observed actions in the video. Distinguish reading saved state from autonomous execution. The demonstration shows process continuity without claiming that the skill keeps working after the assistant closes.
