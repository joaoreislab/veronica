# Veronica — Privacy Notice

Last updated: October 9, 2026. Scope: the current locally distributed Veronica helpers, maintained by [joaoreislab](https://github.com/joaoreislab).

## Local project records

Veronica stores state under the project's `work/veronica/` directory and writes explicitly requested views, captures, exports and recovery bundles. Records can include goals, tasks, notes, file paths, evidence, usage measurements and captured content. These may contain personal or confidential information supplied by the user or host.

The distributed helpers do not include a maintainer-operated collection endpoint, built-in usage telemetry, advertising identifiers or a mechanism that automatically sends those records to the maintainer. Token accounting is local; it is not an adoption counter.

Files remain until the user or another authorized process changes or removes them. Exports, copies, recovery bundles, backups and synchronized folders can retain additional copies. Protect these locations and delete copies separately when appropriate. Do not publish private project state as part of a software distribution.

## Hosts, integrations and GitHub

An AI host may read workspace material and send it to its model provider. Connectors, MCP servers, plugins, cloud synchronization and other tools have their own data flows and policies. Local storage by Veronica does not mean the complete AI workflow stays offline or private.

GitHub handles repository visits, account information and platform analytics under the [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). Information submitted to public issues, comments or pull requests is visible to the public and may be copied by others. The maintainer can see information shared through those channels, but does not receive private local project records merely because someone installs the skill.

For accidentally published information, use GitHub's available reporting or support channels and a non-sensitive repository issue when appropriate. Credentials should be revoked through their provider. Removal from one location cannot guarantee removal of third-party copies.

## No telemetry consent is being requested

This notice does not authorize future telemetry or marketing. Any future collection feature would need a separate design, documented operator and purposes, data minimization, retention and applicable rights procedures before activation. The current project does not offer a hosted analytics or customer-data service.
